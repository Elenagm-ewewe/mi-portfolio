Filosofía de trabajo

Me apasiona el punto donde se cruzan el código limpio y la narrativa visual. No solo desarrollo la lógica de una aplicación, sino que entiendo cómo debe comportarse el color, el ritmo y el movimiento en la pantalla.

Mi objetivo es crear experiencias web que no solo funcionen a la perfección con tecnologías como Angular, Vue o Astro, sino que además tengan un impacto visual profesional y cinematográfico.
